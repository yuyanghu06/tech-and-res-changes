# DLC metadata registration

`tech_res_dlc_metadata.txt` registers the mod's `dlc_tech_res` metadata. It works with the presentation files under `dlc/dlc_ztr/`; it does not replace `.metadata/metadata.json` or the launcher thumbnail.

See [repository map](../docs/architecture/repository-map.md) and [interface, localization and metadata](../docs/visuals/interface-localization-and-metadata.md).
