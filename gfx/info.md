# Visual and media assets

This folder contains map selectors, model definitions, geometry, textures, icons, illustrations and event media. `.asset` files connect named meshes/entities to `.mesh` geometry and `.dds` textures; other scripts refer to those names.

[Cities and military models](../docs/visuals/cities-and-military-models.md) explains map selection and gameplay-versus-appearance boundaries. [Interface, localization and metadata](../docs/visuals/interface-localization-and-metadata.md) explains icons, media aliases and journal presentation. Do not rename or remove assets based only on a folder name such as `unused`; check actual references.
