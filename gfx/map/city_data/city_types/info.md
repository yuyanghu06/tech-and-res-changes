# City building selections

These files select residential, factory and civic model pools. Conditions run against a state region, and the highest matching weight takes priority. Technology checks are shared in `common/scripted_triggers/ztr_city_graphics_triggers.txt`.

Russian additions belong in `ztr_eeu_russian_city.txt`; they require the Russian pack and its native geographic check, retain normal technology progression and allow the existing European definitions to serve as fallbacks. Temporary state-only tests must not override normal Eastern European progression.
