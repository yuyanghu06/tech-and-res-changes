# Milestone records

`milestone.md` is the current project state. `to-do.md` preserves unfinished work. Each multi-pass task has a folder with its scope and acceptance criteria. `history/` contains append-only records; corrections use new entries.

[Late-game performance](late-game-performance/info.md) holds the simulation audit and recommendations; [Russian city appearance](russian-city-appearance/info.md) retains the earlier visual acceptance work.

[Gameplay-preserving performance](behavior-preserving-performance/info.md) follows the completed audit with authorized implementation, differential source checks and independent review.

[Publication](publish-reviewed-updates/info.md) tracks the user-requested push of the reviewed local mod state.
