# Installed mod metadata

`metadata.json` declares the mod's local identity and supported game version. Preserve ID `tech.res`; the current dependency list is empty. `thumbnail.png` is the launcher preview image, copied unchanged from the root artwork and confirmed working by the user.

Existing changelog/TODO files record history and plans. They can be stale; active source and [feature status](../docs/development/feature-status.md) determine current feature claims. The separate DLC-style presentation has its own files under `dlc/dlc_ztr/`.
