# Displayed text

This folder contains eleven language directories. The inspected source has 308 `.yml` files, all with UTF-8 byte-order marks. Preserve those marks, language headers, exact keys and interpolation expressions. Translation accuracy was not audited.

Text keys connect to technologies, goods, laws, events, journal entries, tooltips and inline icons. Some files explicitly replace base-game text. A translated feature name alone is not proof the feature has an active implementation. See [interface and localization](../docs/visuals/interface-localization-and-metadata.md).
